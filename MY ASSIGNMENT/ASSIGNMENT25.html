About Our Project

CSS design tokens are reusable values stored in CSS variables. They help developers manage colours, font sizes, and spacing in one place. Changing a token updates every element that uses that variable.

Design Choices

  • Colours: Dark navy with purple, blue, and pink creates a modern appearance.
  • CSS Variables: Centralised tokens make styling easy to update and maintain.
  • Typography: Different font sizes create a clear visual hierarchy.
  • Layout: Cards, spacing, and gradients improve the visual appearance.
  • Responsive Design: Media queries adapt the layout to smaller screens.
  • Consistency: One stylesheet keeps the entire website visually consistent.
